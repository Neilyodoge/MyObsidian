# MyObsidian

用 Obsidian 将仓库目录打开为宝库，阅读笔记和引用图片。

## 笔记入口

- [小嗯的动作文档](TA/动作/小嗯的动作文档.md)：骨骼动画、蒙皮方案、BAT 烘焙细节、真机测试及挂点。
- [小嗯的 Unity 渲染设置](TA/渲染/小嗯的unity渲染设置.md)：项目设置速查、合批与 Shader 变体管理。
- [UE 各种技术模块](TA/渲染/UE各种技术模块.md)：模块选用、性能工具、光照、纹理、时序重建及毛发。

笔记中的详细推导默认折叠，可在 Obsidian 中点击展开。GitHub 页面直接查看 Markdown 时，Obsidian 专用的图片嵌入和折叠块可能无法完整显示。

## 标题样式

在 Obsidian 的设置 → 外观 → CSS 代码片段中启用 `action-note-headings`。

## 更新

在 Obsidian 中保存修改，然后在 Fork 中查看改动、提交并 Push 到此仓库。
